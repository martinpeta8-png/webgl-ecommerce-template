# High-Converting WebGL Ecommerce Template

**Single-file, production-ready HTML store** following the MASTER PROMPT for high-converting WebGL websites.

## CHASER — Live example

Brand assets from the uploaded zips have been used to configure a ready store for **CHASER** (Jewelry Wholesaler · @chaserofficiial · chaseroficiial@gmail.com).

- **Business**: Jewelry wholesaler (street / charm chains, beaded stacks, crosses)
- **Tagline**: Street jewelry · Wholesale · God over everything
- **Hours**: Open 24 hours
- **Aesthetic**: Dark street luxury (gold on black)
- **Products**: Charm necklaces, beaded bracelets, stacks, wholesale packs
- **Pricing**: Starter Pack R850 · Reseller Pack R2 400 · Bulk quote

The full configured file is available as `chaser.html` in this repo (and as a downloadable artifact). Open it in any browser — no build step.

## How to use for any other brand (only company identity & details)

1. Open `index.html`.
2. Edit the **CONFIG** object (search for `BRAND INPUTS`).
3. Paste your logo as base64.
4. Update products, prices, contact, hours, socials.
5. Open the file in a browser.

## What’s included (master prompt compliant)

- Loader, Auth Gate (Register → OTP → Welcome + Guest + localStorage)
- Sticky blurred nav + mobile hamburger
- Full-viewport Three.js r134 WebGL hero (jewelry geometry for CHASER: chain torus + beads)
- Parallax, ticker, animated counters, 6 feature cards
- Events / drops, filterable product grid, CSS-art gallery
- 3 wholesale pricing tiers (featured = border + shadow only)
- Contact + 24h hours highlight, lead form, footer
- Checkout / enquiry modal (bottom-sheet mobile)
- Social-proof toasts every 14s
- Mobile-first, 44px targets, reduced-motion support, anti-epilepsy lighting
